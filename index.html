01 Tentang

Ide itu murah. Yang susah: jadi website beneran.

Frontend dan backend saya kerjakan sendiri — jadi yang kamu lihat bagus, yang di balik layar juga beres.

Saya Mohammad, seorang Web Developer / Programmer yang fokus membangun pengalaman web yang cepat dan fungsional. Saya mengerjakan sisi yang terlihat pengguna (frontend) sekaligus logika di balik layar (backend), jadi website tidak hanya bagus dilihat, tapi juga berjalan dengan benar.

Salah satu proyek yang sedang saya kembangkan adalah sistem pendeteksi fokus host berbasis CCTV — aplikasi web yang memantau apakah host sedang fokus bekerja atau terdistraksi (misalnya terlalu lama bermain HP atau pandangan tidak ke kamera), dan terhubung ke kamera CCTV kantor untuk monitoring secara real-time.

Bagi saya, website yang baik itu sederhana: cepat dibuka, mudah dipahami, dan menyelesaikan masalah penggunanya. Kalau tiga itu beres, sisanya bonus.

  • ✓ Kode rapi, terstruktur, dan mudah dikembangkan lagi nanti
  • ✓ Tampilan responsif — nyaman di HP, tablet, dan desktop
  • ✓ Komunikasi jelas selama pengerjaan, dari awal sampai rilis
  • ✓ Fokus pada performa dan pengalaman pengguna
